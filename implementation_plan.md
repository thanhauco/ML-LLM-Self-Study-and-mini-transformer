# Independent Learning Trajectory: AI & Machine Learning

This project serves as a structured repository for continuous self-study in machine learning fundamentals, LLM architectures, and evaluation methods.

## Roadmap

### Phase 1: Machine Learning Fundamentals (The Bedrock)

- [ ] **Mathematics for ML**: Linear Algebra, Calculus, Probability, and Statistics.
- [ ] **Classical ML**: Linear/Logistic Regression, Decision Trees, SVMs, Clustering.
- [ ] **Neural Network Foundations**: Backpropagation, Activation Functions, Optimizers (SGD, Adam, etc.).
- [ ] **Deep Learning specialization**: CNNs, RNNs, and the transition to attention.

### Phase 2: LLM Architectures (The Modern Era)

- [ ] **Transformer Deep Dive**: Multi-head attention, Positional Encoding, Encoder-Decoder vs. Decoder-only.
- [ ] **Scaling Laws & Efficiency**: Chinchilla scaling, FlashAttention, Quantization (INT8, FP4).
- [ ] **Advanced Architectures**: Mixture of Experts (MoE), State Space Models (Mamba), Long-context handling.
- [ ] **Fine-tuning & Alignment**: PEFT (LoRA, QLoRA), RLHF (PPO, DPO, GRPO).

### Phase 3: Evaluation & Robustness (The Science of Quality)

- [ ] **Standard Benchmarks**: MMLU, GSM8K, HELM.
- [ ] **RAG Evaluation**: Faithfulness, Relevance, Context Recall (using Ragas/TruLens).
- [ ] **Agentic Eval**: Multi-turn reliability, tool-use accuracy, planning horizons.
- [ ] **Red Teaming & Safety**: Jailbreaking, PII leakage, Bias detection.

### Phase 4: Hands-on Experimentation (The Lab)

- [ ] Implementation of a "Mini-Transformer" from scratch.
- [ ] Benchmarking RAG strategies (chunking vs. vector stores).
- [ ] Fine-tuning a small model (e.g., Phi-3 or Llama-3-8B) for a niche task.

## Repository Structure

- `curriculum/`: Formal notes and reading lists.
- `src/`: Core implementation code.
- `notebooks/`: Exploratory Data Analysis and experimentation.
- `evals/`: Evaluation scripts and datasets.
- `projects/`: Multi-component modules.
