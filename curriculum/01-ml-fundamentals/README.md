# ML Fundamentals Curriculum

This module covers the mathematical and conceptual foundations required for understanding modern machine learning.

## Topics

1. **Mathematics for ML**

   - Linear Algebra (Vectors, Matrices, Eigenvalues)
   - Multivariable Calculus (Gradients, Chain Rule)
   - Probability & Statistics (Distributions, Bayes' Theorem)

2. **Classical ML Algorithms**

   - Linear & Logistic Regression
   - Decision Trees & Random Forests
   - Support Vector Machines (SVM)
   - Clustering (K-Means, DBSCAN)

3. **Neural Network Foundations**

   - Perceptrons & Activation Functions (ReLU, Sigmoid, Tanh)
   - Weight Initialization & Regularization (Dropout, L1/L2)
   - Optimizers (SGD, Momentum, Adam)

4. **Deep Learning Basics**
   - CNNs for Computer Vision
   - RNNs, LSTMs, and GRUs for Sequences
   - Introduction to Attention Mechanisms
